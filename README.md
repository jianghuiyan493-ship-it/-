# 星屿修复站

一个无需安装依赖的像素风网页益智小游戏。点击基地地图上的休息舱、温室、通讯塔，分别游玩数字华容道、旋转水管和信号连线。每种玩法有三关，完成后地图会逐步点亮。九枚关卡印记、三枚设施徽章与一枚基地总成就可在成就图鉴查看。进度保存在浏览器本地。

## 游玩

下载仓库后，直接在浏览器中打开 `index.html`。

运行自动检查：`node test.cjs`。

## 文件

- `index.html`：页面结构
- `styles.css`：界面样式
- `main.js`：谜题与进度逻辑
- `assets/base-map.png`：基地地图
